# ADR-015: Idempotent Ledger Reconciliation & Dual-Transport Fallback

- **ID:** ADR-015
- **Status:** active
- **Decided At:** 1758000000
- **Governs Service:** `ledger-core`
- **Approved By:** `@sarah-staff-eng`

## Context
`ledger-core` connects to `payments-api` over both synchronous gRPC (`weight: 1`) and asynchronous Kafka (`weight: 2`).

## Decision Rule
All `ledger-core` mutations triggered by `refunds-worker` or `payments-api` must carry a deterministic idempotency key so fallback switches from sync gRPC to async Kafka never double-book entries.
